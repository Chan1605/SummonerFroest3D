## 🧩 Game Features

- 🧠 AI 기반 몬스터 FSM 구현 (Trace / Attack / Die)
- 🎯 마우스 휠 줌아웃,피킹 이동, 근접 공격 | 플레이어 4가지 스킬 구현
- 🎮 플레이어 -> 믹사모를 사용한 오토리깅 후 애니메이터 적용
- 🎁 적 처치 시 아이템 드랍
- 🛠 스킬 아이콘 마우스 커서 근접 시 스킬설명 UI 추가
- 📦 오브젝트 풀링 기반 몬스터 리스폰 시스템
- 🪂 타이틀 / 인게임 / 게임오버 / 페이드 인 아웃 화면 완비
